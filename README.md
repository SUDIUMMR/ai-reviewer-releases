# AI Reviewer

選択したコードを Claude（Anthropic の AI）にレビューさせる VS Code 拡張機能の配布用リポジトリです。利用にはご自身の Claude API キーが必要です。

- ダウンロード：右側の「Releases」から `.vsix` を入手してください
- インストール：VS Code の拡張機能ビュー →「…」→「VSIX からのインストール...」
- 紹介ページ：https://amenomix.com/works/ai-reviewer/
- 作り方の解説：https://aoiyume.hatenablog.com/entry/vscode-extension-03
